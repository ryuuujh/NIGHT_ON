# NIGHT ON 웹사이트

개인 마케팅 과제로 기획한 가상 생활가전 **NIGHT ON(나잇온)** 의 제품 소개 사이트입니다.
NIGHT ON은 주변의 빛을 흡수해 원하는 공간에 어둠을 만드는 천장형 전등이라는 가상 제품 콘셉트이며,
실제 판매 제품이 아닙니다. 제품 및 사용 장면 이미지는 AI로 제작했습니다.

작업 기준은 `NIGHT_ON_PROJECT.md`를 따릅니다.

## 폴더 구조

```text
NIGHT_ON/
  NIGHT_ON_PROJECT.md   작업 지침
  index.html            메인 페이지
  css/style.css         스타일
  js/main.js            모바일 메뉴, 앵커 이동, 이미지 누락 안내
  images/               제품·장면 이미지 5장 (PNG)
  audio/night-on-bgm.flac  배경음악
  videos/               (추후 영상 추가 예정, 현재 비어 있음)
  README.md
```

## 배경음악

- 음원 경로: `audio/night-on-bgm.flac` (HTML `<audio>` 요소, MIME `audio/flac`, 반복 재생, 볼륨 15%)
- 사이트에 들어오면 자동 재생을 한 번 시도합니다. 브라우저가 자동 재생을 막으면 조용히 멈추고, 오른쪽 아래 **음악 켜기** 버튼을 누르면 재생됩니다. 끄면 일시 정지되고, 다시 켜면 멈춘 위치부터 이어집니다.
- 버튼은 키보드(Tab → Enter/Space)로도 조작할 수 있습니다.
- 파일이 없거나 브라우저가 FLAC을 지원하지 않으면 버튼에 **음원 재생 불가**가 표시되고 나머지 기능은 그대로 동작합니다.
- **교체 방법**: 같은 이름의 FLAC 파일로 덮어쓰면 됩니다. 다른 형식(예: MP3)으로 바꾸려면 `index.html`의 `<source>` 태그에서 `src`와 `type`(예: `audio/mpeg`)을 함께 바꿉니다. 확장자만 바꾸면 재생되지 않습니다.

## 로컬 실행 방법

정적 사이트라서 서버 설치가 필요 없습니다. 아래 중 하나를 쓰면 됩니다.

### 1) Python 내장 서버 (권장)

프로젝트 폴더에서 PowerShell 또는 터미널을 열고:

```powershell
cd <프로젝트 폴더>
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다. 종료는 `Ctrl + C`.

### 2) VS Code Live Server

VS Code에서 `index.html`을 열고 우클릭 → **Open with Live Server**.

### 3) 파일을 직접 열기

`index.html`을 더블클릭해도 열립니다. 모든 경로가 상대 경로라 그대로 동작합니다.

| 1440px | 메인 비주얼에서 밝은 창문과 전등이 함께 보이는지. 장면 사진이 글과 좌우로 나란히(낮의 휴식은 사진 왼쪽, 홈시네마는 사진 오른쪽) 놓이는지 |

3. 낮과 밤 (네이비) — NIGHT OFF / NIGHT ON 비교 영역
4. 낮의 휴식 (웜화이트)
5. 홈시네마 (네이비)
6. 사용 방법 (웜화이트) — 4단계
7. FAQ (네이비) — 질문을 누르면 답이 펼쳐짐
8. 가격 (웜화이트) — 기획 가격 399,000원, 구매하기 → 구매 체험 모달

공통으로 확인할 것:

- 상단 메뉴 4개(제품 소개, 낮과 밤, 사용 장면, FAQ)와 푸터 링크가 해당 섹션으로 이동하는지

- 낮과 밤 비교: 손잡이를 마우스로 끌거나(모바일은 손가락), 손잡이를 Tab으로 선택한 뒤 ← → 키로 움직일 때 밤 영역이 바뀌는지. 손잡이가 사진 밖으로 나가지 않는지
- 모바일에서 비교 사진 위를 위아래로 쓸어 넘길 때 페이지가 스크롤되는지(좌우로 쓸면 슬라이더)
- FAQ 질문을 눌러 답이 펼쳐지고 + 표시가 − 로 바뀌는지. 다시 누르면 닫히는지. Tab으로 질문에 가서 Enter/Space로도 되는지
- Tab 키로 이동할 때 포커스 테두리가 보이는지(네이비 배경은 라벤더, 웜화이트 배경은 네이비)
- 모바일 메뉴: 버튼으로 열고 닫기, Esc로 닫기, 링크 선택 시 닫힘
- NIGHT ON 로고를 누르면 맨 위로 가는지
- 스크롤하면 아래 섹션이 살짝 떠오르며 나타나는지. Windows "애니메이션 효과" 끄기(설정 → 접근성 → 시각 효과)에서는 바로 보이는지

### 구매 체험 모달 메모

- 네이티브 `<dialog>`의 `showModal()`을 써서 포커스 가둠, 배경 요소 키보드 차단(inert), Escape 닫기, 음악 버튼보다 위에 표시(최상위 레이어)를 브라우저 표준으로 처리합니다.
- 열릴 때 포커스는 수량 늘리기 버튼으로, 닫힐 때는 눌렀던 구매하기 버튼으로 돌아갑니다. 닫기 버튼, Escape, 모달 바깥 클릭으로 닫힙니다.
- 합계는 `aria-live="polite"` 영역이라 수량을 바꾸면 보조 기술이 새 합계를 읽습니다. 수량 1개·5개에서는 해당 방향 버튼이 비활성화됩니다.
- 모달을 열고 닫아도 배경음악 상태는 건드리지 않습니다.

### 구현 방식 메모

- 비교 슬라이더는 사진 위에 투명한 `<input type="range">`를 겹쳐 두고, 그 값을 CSS 변수로 넘겨 밤 사진의 `clip-path`와 기준선 위치를 바꿉니다. 두 사진의 크기는 항상 같고 보이는 영역만 달라집니다. 마우스·터치·키보드 입력은 브라우저 기본 동작을 그대로 쓰므로 별도 라이브러리가 없습니다. `touch-action: pan-y`로 세로 터치는 페이지 스크롤에 넘깁니다.
- FAQ는 `<details>/<summary>`라서 JavaScript 없이도 열리고 닫힙니다.
- 섹션 등장 효과는 JavaScript가 `<html>`에 `js-reveal` 클래스를 붙였을 때만 켜집니다. 스크립트가 실패하거나 움직임 줄이기 설정이면 처음부터 모두 보입니다. 보험으로 로드 4초 뒤에는 남은 요소도 모두 표시합니다.

- Vercel에서 저장소를 가져올 때: **Framework Preset = Other**, Root Directory = 비움(저장소 루트), Build Command = 비움, Output Directory = 비움. Install Command도 비웁니다.

- `audio/night-on-bgm.flac`(약 30MB)은 GitHub 단일 파일 한도(100MB) 안이라 Git LFS 없이 올립니다. LFS를 쓰면 Vercel이 기본 설정에서는 실제 파일 대신 포인터를 받아 재생되지 않으니 쓰지 않습니다.

Edge(Chromium)를 DevTools 프로토콜로 조작해 실제 마우스 드래그, 터치 드래그, 방향키, Enter/Space, Escape 입력을 보내 동작을 확인했고, 콘솔 오류가 없음을 확인했습니다. 1440×900 데스크톱과 360×800 모바일(터치) 환경, 움직임 줄이기 설정, JavaScript 비활성 상태를 검사했습니다.
